- Important discovered limitation: PostgreSQL's global default `PUBLIC EXECUTE` on new functions is **not** removed by a per-schema default REVOKE. A local fixture confirmed effective function EXECUTE can remain true even while schema USAGE denies access. All future functions must explicitly revoke PUBLIC/guest EXECUTE in the same transaction and be verified, without changing shared global defaults absent separate approval. The candidate explicitly revokes its created functions; a later inadvertent schema USAGE grant would otherwise create exposure.
