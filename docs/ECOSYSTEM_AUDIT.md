## Data sources available for legitimate expansion

All present in `package.json` and installed locally. Pinned, versioned, MIT/CC0:

| Package | Size | License | Yields |
|---|---|---|---|
| `color-name-list` | 19 MB | **MIT** | named colours (palettes, gradients) |
| `unicode-emoji-json` | 840 KB | **MIT** | emoji + names + groups + skin tones |
| `simple-icons` | 26 MB | **CC0-1.0** | 3,000+ brand marks |
| `@iconify/json` | 673 MB | **MIT** (per-collection SPDX) | 200k+ icons across sets |
| `google-font-metadata` | — | **MIT** | 1,908 font families |

`scripts/import-library.mjs` already contains a **conservative SPDX allow-list**
(MIT, Apache-2.0, CC0-1.0, CC-BY-4.0/3.0, BSD-3-Clause, ISC, Unlicense, OFL-1.1)
that excludes CC-BY-SA, CC-BY-NC and GPL. This audit reuses it rather than
inventing a second policy.

## Missing / incomplete (what this work must address)

1. **No colour palettes** — `color_palettes` table exists, 0 rows; nothing public.
2. **No icons** — `icon_library` table exists, 0 rows; nothing public.
3. **No quotes / poetry / wishes library.**
4. **No YouTube title / description / tag tools.**
5. **No business-name, slogan or marketing-copy studio.**
6. **No developer text utilities.**
7. **No content-planning tools.**
8. **No language registry** — bios/pools are `en | hi | hg` only, no RTL support.
9. **No tool discovery taxonomy** — 12 flat tools, no categories.
10. **No favourites / history** across generators.
11. **No bulk export** as JSON/CSV.
12. **Search has no tag, platform or tone facets.**

Items 1–2 are the honest, license-clean wins: the data is already vendored and
licensed. Items 3–8 need genuinely new authored or derived content.

## External blockers found during audit

- **Playwright browsers cannot be downloaded** in this environment (CDN
  unreachable), so browser-driven suites cannot run here. jsdom is used instead.
- **Vercel preview deployments are auth-protected**, so previews cannot be
  verified anonymously; production is verified directly.
- **No quote/poetry corpus exists in any vendored package.** Any such library must
  be authored in-project or come from an explicitly licensed source; inventing
  thousands of entries or shipping unattributed text is not acceptable.
