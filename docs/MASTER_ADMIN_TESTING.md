# Tests and evidence

Current shared-project decision: [review and boundaries](MASTER_ADMIN_SHARED_PROJECT.md). `npm run test:admin-identity` tests the server identity/read gate with mock verification and an intercepted Supabase SDK call, not live Auth. Current exact test commands and results are recorded in [progress](MASTER_ADMIN_PROGRESS.md). `npm run test:admin-isolated-foundation` and `npm run test:admin-isolated-workflow`, and `npm run test:admin-isolated-permissions` exercise candidate migrations in disposable PGlite with synthetic roles/users. They cover table count, RLS policy presence, default denial metadata, constraints, append-only triggers, rollback, assigned reviewer and state integrity. They do not prove actual Supabase behavior, PostgREST exposure, role ownership, concurrency, cryptographic identity, MFA, active revocation, server RBAC, audit completeness, public integration, real-device UX or performance. `npm run test:admin-bio-domain` tests standalone input validation, not real API integration or authoritative platform counting rules. The broader [test and recovery plan](admin-backend-phase4/TEST-AND-RECOVERY.md) remains open. No test or security assessment is marked passed unless executed.

Additional local tests: `test:admin-private-commands` exercises private fixture SQL, and `test:admin-auth-flow` mocks password/TOTP/logout. Browser screenshots at `admin-preview/current/` are local viewport emulation. Neither proves real authentication or hosted security.
