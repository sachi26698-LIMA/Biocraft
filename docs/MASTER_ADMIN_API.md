# Admin API

No real Admin API, live session resolver, RBAC, login, MFA or privileged endpoints are implemented or exposed. `admin-backend/server/auth-flow.mjs` includes provider password/TOTP/logout primitives with injected mandatory rate limiting; no secure session/token store, rate limiter, endpoint or hosted Auth verification exists. Tokens must never be returned to browsers. `admin-backend/server/identity.mjs` contains a server-side provider verification/read-authorization boundary pinned to the existing project, but has no wired persistent session/membership resolver, is not served or deployed, and has only mock/intercepted network tests. It cannot authorize mutations; those must recheck state transactionally. Existing `src/admin/backend.ts` is an unavailable contract, not an API adapter. The historical [API draft](master-admin-blueprint/API_CONTRACTS.md) is a design input only and its roles/permissions must be reconciled with the eight-role requirement. Do not call default-deny schema directly from a browser; data access must follow authenticated, scoped, transactional commands with protected audit, replay handling and verified session/MFA semantics. No release API exists. Missing APIs return unavailable rather than simulated success in the existing Preview contract.

`004_private_draft_commands.sql` adds private, ungranted local-only create/list/submit/review functions with permission and session checks and transactional success audit; mock request claims are forgeable in local SQL. No real API uses them, no production grant or migration has been approved, and no publishing function exists.
