`supabase-roots.pem` contains **public CA certificates**, not DB credentials.
Both PEM blocks are verbatim from the official [Supabase CLI templates at b77f761](https://github.com/supabase/cli/tree/b77f7611dff5082a8cbfdd105d3a630c349aa470/apps/cli/src/command-internal/supabase-ca-templates), `prod-ca-2021.ts` and `prod-ca-2025.ts`. These roots are trusted only by the restricted server-side PostgreSQL client. TLS certificate and hostname verification stay enabled. When Supabase rotates a root, verify it against the official distribution and update `tests/admin-pool-config.mjs` as well.
