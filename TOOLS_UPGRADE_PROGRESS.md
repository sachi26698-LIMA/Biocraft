## Cross-cutting implementation

- All 12 registered generator chunks lazy-load; an accessible loading status appears while a route module loads. Routes, SEO titles and 48 static route shells are preserved.
- Unified mode toggle, remembered preference, and full **Reset tool** remount action. Download controls export local plain UTF-8 text; editable output is added where text output is the tool’s result. Symbols remain a selectable glyph library rather than an artificial “generated text editor.”
- Fancy Fonts / Stylish Name expose meaningful style collections; Hashtags now render broad/medium/focused/keyword groups and editable custom sets. Mode defaults intentionally use simple presets; no unsupported audience or availability service has been simulated.
- Existing copy error handling remains; invalid Hashtag submissions now keep the prior result set. No API requests, uploads, new storage schema, or external analytics were added.
- Persisted light/dark theme remains available via `biocraft:theme`.
